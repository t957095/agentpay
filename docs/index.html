AgentPay ⚡🤖

Pay-per-request for APIs, settled on Solana in under a second.
AI agents can't pass KYC or hold credit cards. AgentPay turns any endpoint into a paid endpoint with 3 lines of code — the transaction is the credential.

Live devnet demo

1Agent requests GET /api/brief → server answers 402 Payment Required with payment instructions.
2Agent signs a 5,000-lamport transfer with a unique memo on Solana devnet.
3Agent retries with the tx signature → gateway verifies amount + memo on-chain → data served.

Run it yourself:

npm install
AGENTPAY_MERCHANT=<devnet-address> npm run demo
npm run agent -- http://localhost:3402/api/brief
